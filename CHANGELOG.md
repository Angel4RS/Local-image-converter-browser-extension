# Changelog / Historial de cambios

## v1.2.1
- Renamed to **Local image converter** (extension name and window title).
- Added "Created by Angel4RS" to the extension description and `author` in the manifest.
- Se renombró a **Local image converter** y se añadió "Creado por Angel4RS" a la descripción.

## v1.2.0
- Interface and messages now follow the browser language: Spanish, English, Portuguese, French and Japanese (English as fallback).
- La interfaz y los mensajes siguen el idioma del navegador.

## v1.1.0
- Notification when the download is complete.
- New buttons: *Deselect* and *Clear selected*; the selection is cleared after a download.
- Reorganised interface with icons, section titles, creator credit, GitHub link and Ko-fi button.
- Custom background image, new angel-wings icon.
- More robust folder and file names (fixes the "Invalid filename" error) with automatic fallbacks.
- Notificación al completar la descarga, botones de selección, interfaz reorganizada, fondo propio, icono de alas y corrección del error "Invalid filename".

## v1.0.0
- First version: detects images on the page, converts AVIF/WebP to JPG, PNG, GIF or WebP in batches, quality slider, subfolder inside Downloads, ZIP download and drag and drop.
- Primera versión: detección de imágenes, conversión por lotes, calidad, subcarpeta, ZIP y arrastrar y soltar.
